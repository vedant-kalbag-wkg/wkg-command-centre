# Map Library Choice — v1.1 VIEW-01

## TL;DR Recommendation
**MapLibre GL JS via `react-map-gl/maplibre`** — vector tiles, free with a community tile provider, React 19/Next 16 SSR-safe, brand-themable via style JSON.

## Options Considered
| Option | Cost @ scale | Clustering | Brand-style ergonomics | React/Next.js fit | Bundle size |
|---|---|---|---|---|---|
| Leaflet (`react-leaflet@5` + `leaflet@1.9.4`) | Free (OSM tiles) | Good — `leaflet.markercluster@1.5.3`, mature, raster only | Hard — raster CSS overrides, no native style spec | OK; needs `dynamic(ssr:false)`, ref churn on R19 | ~45 KB gz core + plugin |
| **MapLibre GL JS (`react-map-gl@8.1.1` + `maplibre-gl@5.24.0`)** | **Free w/ MapTiler/Protomaps free tier (≥30 internal users = $0)** | **Native `cluster:true` on GeoJSON source — zero plugin, GPU-rendered** | **Full Mapbox Style Spec JSON — Azure brand trivial** | **R19 + Next 16 supported, SSR-safe via dynamic import, TS types first-class** | ~210 KB gz |
| Mapbox GL JS (`react-map-gl@8.1.1` + `mapbox-gl@3.23.0`) | $0.50–$5 per 1k loads after 50k free; commercial license + token | Same as MapLibre (parent fork) | Same Style Spec | Same | ~230 KB gz |
| Google Maps (`@vis.gl/react-google-maps@1.8.3`) | **$7 / 1k dynamic map loads after $200 credit** — material even at low traffic; key reuse irrelevant (server geocoding ≠ JS API billing) | `@googlemaps/markerclusterer` — solid | Limited — `styles[]` array only, no full style spec | R19 peer dep set, Next 16 OK | ~80 KB gz (loader-deferred) |

## Rationale
Reusing the Google key is a trap — Maps JavaScript API is billed separately from Geocoding and the **per-load pricing eats the $200 credit fast** even at internal-tool traffic. Mapbox GL is the same engine as MapLibre but adds a token + commercial license for no functional benefit here. Leaflet is raster-only, harder to brand-theme, and clustering is a plugin. MapLibre wins on every axis: free tiles via MapTiler/Protomaps, native source-level clustering at 1k+ markers (GPU, no plugin), full Mapbox Style Spec for trivial Azure `#00A6D3` / Graphite theming, mature `react-map-gl` v8 with React 19 and Next.js App Router SSR-safe patterns, and TypeScript-first.

## Implementation note
```bash
npm install react-map-gl@^8.1.1 maplibre-gl@^5.24.0
```
```tsx
// app/(dashboard)/map/_components/kiosk-map.tsx
"use client";
import Map, { Source, Layer } from "react-map-gl/maplibre";
import "maplibre-gl/dist/maplibre-gl.css";

export function KioskMap({ geojson }: { geojson: GeoJSON.FeatureCollection }) {
  return (
    <Map
      initialViewState={{ longitude: 0, latitude: 20, zoom: 2 }}
      mapStyle="https://api.maptiler.com/maps/streets-v2/style.json?key=…"
      style={{ width: "100%", height: "100%" }}
    >
      <Source id="kiosks" type="geojson" data={geojson} cluster clusterRadius={50}>
        <Layer id="clusters" type="circle" filter={["has", "point_count"]}
          paint={{ "circle-color": "#00A6D3", "circle-radius": ["step", ["get", "point_count"], 16, 25, 22, 100, 28] }} />
        <Layer id="cluster-count" type="symbol" filter={["has", "point_count"]}
          layout={{ "text-field": "{point_count_abbreviated}", "text-size": 12 }}
          paint={{ "text-color": "#FFFFFF" }} />
        <Layer id="unclustered" type="circle" filter={["!", ["has", "point_count"]]}
          paint={{ "circle-color": "#00A6D3", "circle-radius": 6, "circle-stroke-color": "#121212", "circle-stroke-width": 1 }} />
      </Source>
    </Map>
  );
}
```
Load the page via `next/dynamic(() => import("./kiosk-map"), { ssr: false })`. Get a free MapTiler key (or self-host Protomaps PMTiles on Vercel Blob to remove the third-party dep entirely).
