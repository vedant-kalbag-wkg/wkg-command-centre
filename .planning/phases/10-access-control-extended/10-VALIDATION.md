## Sampling Rate

- **After every task commit:** `npm run test:unit -- <files-in-task-scope>` (typically `src/lib/casl src/lib/auth tests/db` for this phase)
- **After every plan wave:** `npm test` (vitest full — unit + integration projects)
- **Before `/gsd-verify-work`:** `npm test && PLAYWRIGHT_BASE_URL=$BRANCH_ALIAS npx playwright test tests/access-control` — Playwright runs against the Vercel preview git-branch alias per CLAUDE.md `## Vercel preview env vars` and `## Playwright specs against preview deploys`. `--list` is NOT sufficient evidence (Plan 10-08 Step 6 enforces this).
- **Max feedback latency:** ≤ 30 seconds for the per-task quick run.
