## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer → migration journal | Edits to `_journal.json` change which SQL files drizzle-kit applies on `migrate`; mis-edits can apply the wrong file, skip a file, or apply files in the wrong order. |
| journal → prod DB | Once committed, this journal change controls every future `drizzle-kit migrate` against every environment (preview, prod, fresh clones, CI throwaway DBs). |
